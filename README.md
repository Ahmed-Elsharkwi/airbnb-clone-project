# airbnb-clone-project
## project Goals
 This project emphasizes real-world practices including secure API development, version-controlled team collaboration, effective project documentation, and automated deployments.

## Tech Stack

- **Backend Framework**: Django
- **Database**: MySQL
- **API & Query Language**: GraphQL
- **Version Control**: GitHub
- **CI/CD**: GitHub Actions / Jenkins / GitLab CI (based on team choice)
